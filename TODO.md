# План редизайна: Gamified Bento UI 🍱

## 1. Концепция и Визуал
- **Стиль**: Bento Grid (плиточный интерфейс) + Modern Dark Mode.
- **Цвета**: Глубокий тёмный фон (`#09090b`), яркие неоновые акценты (Electric Blue, Neon Purple) для важных кнопок.
- **Типографика**: Массивные заголовки (Inter/system-ui), строгий и читаемый текст.
- **Строгие ограничения**: 
  - ПОЛНОЕ отсутствие эмодзи во всем интерфейсе (включая иконки, пустые состояния и текст).
  - Минималистичный переключатель темы (иконки в виде простых SVG, а не эмодзи ☀️/🌙).

## 2. Глобальный Layout и Навигация
- **Navbar**: Плавающий (floating) navbar с размытием фона (blur), минималистичный логотип. 
- **Theme Toggle**: Строгая SVG-иконка (солнце/луна) без лишних стилей.
- **Hero-блок**: Крупный Bento-grid на главной странице, где собраны статистика, ближайшее мероприятие и CTA.

## 3. Функционал и Страницы
- **Афиша (`/events`)**: 
  - Карточки мероприятий в виде аккуратных блоков с hover-эффектами (лёгкий scale и glow).
  - Бесконечная сетка.
- **Страница мероприятия (`/events/:id`)**:
  - Bento-раскладка: обложка, описание, погода, и чат/комментарии — всё в виде отдельных плиток.
- **Личный кабинет (`/dashboard`)**:
  - Таблица лидеров (Leaderboard) и геймификация (уровни, XP).
  - Сетка ачивок (бейждей) за посещение мероприятий.
- **Погода (`/explore`)**:
  - Минималистичные карточки прогноза без лишних отвлекающих элементов.

## 4. Архитектура и State
- Использование Redux для хранения XP, ачивок и комментариев.
- Поддержка "умных рекомендаций" (заглушка логики на клиенте).

## 5. Этапы реализации
1. Обновление `index.css` (цвета, Bento-сетка, удаление эмодзи, SVG-иконки).
2. Переработка `App.jsx` и Navbar (минималистичный переключатель темы).
3. Создание главной страницы (Hero Bento Grid).
4. Редизайн Личного кабинета (XP, Ачивки).
5. Обновление Афиши и Детальной страницы.
6. Полировка и QA.
